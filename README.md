# Maison Menu – Restaurant Menu Manager

A React Native / Expo menu management app with an elegant restaurant-inspired interface.

## Features
- Curated sample menu with starters, main courses and desserts, including South African favourites.
- Search by dish name, description or course.
- Interactive course filter with a clear-filter action and live result count.
- Menu overview statistics: total dishes, course breakdown, combined listed price, average price, most ordered and most liked dishes.
- Add menu items and persist the menu locally with AsyncStorage.
- Open a dish to view its details and remove it from the menu.

## Run the app
1. Install Node.js (LTS).
2. In this project folder run `npm install`.
3. Run `npx expo start`.
4. Press `w` for web, or scan the QR code with Expo Go on a phone.

## Notes
The order and like figures in the sample data are illustrative demonstration statistics, not live restaurant sales data. Newly added dishes begin with zero orders and likes.
