**Easy Chef App**

Easy Chef is an Mobile Application to help chefs manage menu items from a mobile-friendly interface.

**Feature**

- Home Screen: Shortcuts to add menu items and view the menu.
- Menu Items Screen: Browse dishes, search by name, and filter by course.
- Add menu item: Enter a dish name, description, course and price.
- Item details: View information about a selected dish.
- Edit and Delete: Manage existing dishes where implement.
- Statistics: View menu counts by course and price summaries
- Chef profile: Edit profile details and select a profile picture and can logout too.
- Sign up: Where the user creates an account in the app and add their required details.
- Login: If is a user is an retuning user of the app and they need to enter their email and password.
- SplashScreen: The page that will load when an user goes into the application.

**Explanation of the Screens**

*Home Screen* 
The screen contains the name of the chef signed in.
Button where a user can add menu items.
Button a user can view the menu items.
There is a home page, statistics and profile button at the bottom of the page

*Add Menu Item*
The user enters the dish name, a description, the type of course and price of the dish.
There is a button the user press to add the dish and will be redirected to the menu list screen with the added dish.

*Item details*
The user can search for an item.
The top right is a filter button
Then there is items of all the courses and dishes the user has added.
The button the user can use to add item/dish and it will take them to the add menu item screen.
There is home and statistics button.

*Statistics*
There is an overview that show the total items, total value and average price.
There is Highlights that shows the most expensive dish, the cheapest dish, most ordered dish and most loved dishes
There is trending items too
